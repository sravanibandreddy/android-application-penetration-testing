Privacy Policy

Android Security Scanner

Last Updated: November 5, 2026

1. Introduction

Android Security Scanner is an application designed to analyze APK files and PDF documents for potential security risks.

2. Information Access

The application may access installed application information, APK files and PDF documents selected by the user, and related metadata required for security analysis.

3. Data Collection and Storage

The application is designed to perform security analysis locally on the device. Selected files are processed for analysis and are not intentionally uploaded to an external server. Reports may be saved to a location selected by the user.

4. Data Sharing

We do not sell personal information. Scanned documents and application information are not intentionally shared with third parties.

5. File Access

Files are accessed for user-requested scanning and report operations.

6. Security

Reasonable measures are taken to protect information processed by the application. Absolute security cannot be guaranteed.

7. Children's Privacy

The application is not specifically designed to collect personal information from children.

8. Policy Changes

This policy may be updated when application features or privacy practices change.
